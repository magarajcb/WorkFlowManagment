# Workflow Management System

A full-stack MERN Workflow Management application that helps users create projects, manage tasks, track progress, and organize their workflow efficiently.

## 🚀 Live Demo

**Frontend:** https://cbworkflowmanagment.netlify.app

**Backend API:** https://workflowmanagment.onrender.com

## 📌 Features

### Authentication
- User Registration
- User Login
- JWT Authentication
- Protected API Routes

### Project Management
- Create Project
- View All Projects
- View Single Project
- Delete Project

### Task Management
- Create Task
- View Tasks by Project
- Update Task Status
- Delete Task

### Task Status Tracking
- Todo
- In Progress
- Completed

## 🛠 Tech Stack

### Frontend
